Atividades de JS, usando o console

IF – ELSE
1. Faça um programa que verifique a idade do usuário. Se a idade for menor que 18 anos, exiba uma mensagem informando que ele é menor de idade. Se a idade for maior ou igual a 18 anos e menor que 60 anos, exiba uma mensagem informando que ele é adulto. Se a idade for maior ou igual a 60 anos, exiba uma mensagem informando que ele é idoso.
2. Faça um programa que solicite ao usuário que informe sua idade. Se a idade digitada for maior ou igual a 18 anos, exiba a mensagem: "Você pode dirigir". Caso contrário, exiba a mensagem: "Você ainda não pode dirigir".
3. Faça um programa que solicite ao usuário que digite um número inteiro. Se o número for positivo, exiba uma mensagem informando que ele é positivo. Se o número for negativo, exiba uma mensagem informando que ele é negativo. Se o número for igual a zero, exiba uma mensagem informando que ele é zero. (A atividade deve ser realizada no Console.)
4. Atividades relacionais: Faça um programa que solicite ao usuário que informe sua altura, em metros, e seu peso, em quilogramas. Em seguida, o programa deverá calcular o Índice de Massa Corporal (IMC) utilizando a fórmula: IMC = peso / (altura * altura). Após calcular o IMC, o programa deverá verificar se o resultado está dentro do intervalo considerado saudável, de 18,5 a 24,9. Por fim, deverá exibir uma mensagem informando se o IMC está ou não dentro desse intervalo.
5. Faça um programa que solicite ao usuário que digite uma nota de 0 a 10. Se a nota for maior ou igual a 7, exiba uma mensagem informando que o aluno foi aprovado. Caso contrário, exiba uma mensagem informando que o aluno foi reprovado. A prática leva à perfeição!
